# Osama Thara — Analytics & Customer Success Portfolio

A premium, highly-responsive personal portfolio and resume landing page for Osama Thara. Designed with a modern, data-centric aesthetic to highlight professional experience in Business Analytics, Key Account Management, and Customer Success.

**Live Deployment:** [osamathara.vercel.app](https://osamathara.vercel.app)

## Features

- **Dark Mode Aesthetic:** Sleek, modern design tailored for a premium feel.
- **Bento Grid Layout:** Optimized content organization to highlight key statistics and skills.
- **Glassmorphism UI:** Translucent cards and interfaces to add depth.
- **Dynamic Animations:** Scroll-triggered micro-animations using Intersection Observer.
- **Fully Responsive:** Adapts seamlessly to mobile, tablet, and desktop viewports.

## Technologies Used

- **HTML5:** Semantic structure.
- **CSS3:** Vanilla CSS featuring CSS Variables, Grid, Flexbox, and custom animations.
- **JavaScript (ES6):** Logic for mobile menu toggling and scroll-based fade-in effects.
- **Google Fonts:** Utilizing 'Inter' and 'Outfit' for refined typography.

## Local Development

If you want to view or modify this project locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/tharaosama-cloud/osamathara-resume.git
   ```
2. Navigate to the project directory:
   ```bash
   cd osamathara-resume
   ```
3. Open `index.html` in your preferred web browser. No local server or build tools are required.

## Design Reference

The design principles and layout structure were inspired by modern tech portfolios and operations leader landing pages, adapting high-end elements like bento boxes and neon accents into a professional, data-driven narrative.
